# 1MM 보고서 · 수학도서관

수학도서관 1개월 학습보고서(1MM)를 선생님들이 함께 작성하는 프로그램입니다.

- 주소: https://hongs-sudo.github.io/1mm-report/
- PC 크롬·엣지에서 **바탕화면에 설치** 버튼으로 앱처럼 설치할 수 있습니다.
- 아이패드·갤럭시탭: 같은 화면을 터치에 맞춰 씁니다. (사파리 공유 → 홈 화면에 추가)
- 휴대폰: 보고서의 모든 항목을 세로로 확인하는 보기 전용 화면입니다.

## 처음 한 번 해야 할 일 (원장님)

1. **Firestore 권한 규칙 게시**
   Firebase 콘솔 → `mathlibrary-1mm` → Firestore Database → **규칙** 탭에
   이 저장소의 [`firestore.rules`](firestore.rules) 내용을 그대로 붙여넣고 **게시**합니다.
   (이걸 안 하면 로그인 후 "정보를 불러오지 못했습니다"가 나옵니다.)
2. 원장님 구글 계정(ilmvm66@gmail.com)으로 로그인하면 자동으로 관리자가 됩니다.
3. **선생님 계정** 메뉴에서 선생님들의 구글 이메일과 이름을 등록합니다.
4. **학생 · 담임 배정** 메뉴에서 학생을 등록하고 담임·부담임을 정합니다. (엑셀에서 여러 명 붙여넣기 가능)
5. 데일리 리포트를 쓰는 기기라면 **설정 · 연동**에 데일리 리포트 동기화 저장소와 토큰을 넣습니다. (그 기기에만 저장)

## 권한

| 학생 등록 · 담임 배정 · 선생님 계정 | ○ | – | – |

## 기본 내용 불러오기

- **데일리 리포트**: 동기화 저장소(또는 백업 JSON 파일)에서 기간 안의 출결·과제 달성률·안 해온 과제·진도·태도 평균을 계산해 담임/부담임 줄에 채웁니다.
- **자료 올리기**: 입회원서 사진, 수업 기록 엑셀·CSV를 올리면 작성 화면 옆에 띄워 놓고 보며 입력합니다. 엑셀은 학생 이름이 있는 칸을 찾아 표시합니다. 올린 자료는 서버에 저장하지 않습니다.
- **AI 자동 인식 (나중에)**: [`worker/ai-proxy.js`](worker/ai-proxy.js)를 Cloudflare Worker로 올리고, 설정에 주소를 넣으면 "AI로 읽어서 채우기" 버튼이 켜집니다.

## 2인 수업

담임·부담임이 나눠 수업하면 출결·과제를 선생님별 줄로 쓰고 합계 줄이 자동 계산됩니다. 같은 날 두 선생님 기록이 있으면 각 선생님 이름으로 각각 셉니다. 교사명은 "담임 ○○○ · 부담임 ○○○"으로 표시됩니다.

## 파일 구성
